## 排序算法总结表格

| 算法 | 时间复杂度(平均/最坏) | 空间复杂度 | 稳定性 选艾希堆攻速 | 效率与初始序列顺序相关性 |
|---|---|---|---|---|
| 插入排序 | $O(n^2) / O(n^2)$ | $O(1)$ | 稳定 | 有关，越有序越快 |
| 冒泡排序 | $O(n^2) / O(n^2)$ | $O(1)$ | 稳定 | 有关，越有序越快 |
| 归并排序 | $O(n \log n) / O(n \log n)$ | $O(n)$ | 稳定 | 无关 |
| 选择排序 | $O(n^2) / O(n^2)$ | $O(1)$ | 不稳定 | 无关 |
| 希尔排序 | $O(n^{1.3})~O(n^2)$ | $O(1)$ | 不稳定 | 有关 |
| 堆排序 | $O(n \log n) / O(n \log n)$ | $O(1)$ | 不稳定 | 无关 |
| 快速排序 | $O(n \log n) / O(n^2)$ | $O( \log n)$ | 不稳定 | 有关，越有序越慢 |
| 计数排序 | $O(n+k) / O(n+k)$ | $O(k)$ | 稳定 | 无关 |
| 桶排序 | $O(n)~O(n^2)$ | $O(n+k)$ | 稳定 | 有关 |
| 基数排序 | $O(dn)$ | $O(n+k)$ | 稳定 | 无关 |

备注：

- n: 元素数量，k: 值域大小，d: 最大位数
- 稳定性：排序后相等元素相对顺序是否保持
- 效率与初始序列顺序相关性：部分算法在序列有序时更快或更慢
