## A 定界符与编号

### A1 行内与行间

| 效果 | 源码 |
| --- | --- |
| 正文里的行内公式 $a^2+b^2=c^2$ 与文字同排 | `$a^2+b^2=c^2$` |
| 行间公式（独立成行、居中）见下方成对示例 | `$$` 换行 内容 换行 `$$` |
| 行内也能放大分式 $\dfrac{a}{b}$，不撑行高用 `\tfrac` | `\dfrac{a}{b}` |

块级公式的正确写法——`$$` 单独占一行，首尾各一行：

$$
\int_{0}^{1} x^{2}\,\mathrm{d}x=\frac{1}{3}
$$

```latex
$$
\int_{0}^{1} x^{2}\,\mathrm{d}x=\frac{1}{3}
$$
```

### A2 编号与交叉引用

手动编号，标签以括号形式贴在公式右侧：

$$
f(x)=x^{2}+1 \tag{A}
$$

```latex
$$
f(x)=x^{2}+1 \tag{A}
$$
```

标签加星号则只留字母、不带括号：

$$
f(x)=x^{2}+1 \tag*{B}
$$

```latex
$$
f(x)=x^{2}+1 \tag*{B}
$$
```

交叉引用不靠 `\label`（本站 `\eqref` 编译失败），直接把页面锚点写成链接：[见 A2](#a2-编号与交叉引用)。

<Callout type="warning">
本站 KaTeX 不会自动编号：`\begin{equation}`、`\begin{align}` 都能编译通过，但公式左侧**不会出现 (1)(2)**，想要编号只能手写 `\tag{}`；`\label` / `\eqref` 会直接编译失败，交叉引用请改用页面锚点链接。
</Callout>

### H2 本站 KaTeX 差异与红线

这张表是踩坑记录，写法都是站在**本站**（KaTeX 0.16.47 + MDX）的角度：

| 写法 | 本站实测结果 | 建议 |
| --- | --- | --- |
| `$x$` | 行内公式，正常 | 首选 |
| `$$` 独占一行夹住内容 | 块级公式，居中，正常 | 多行结构一律用这个 |
| `$$x+1$$` 写在同一行 | 退化为**行内公式**，不居中 | 拆成三行写 |
| `\[ x \]` | **完全不渲染**，页面显示字面 `[` 加源码 | 改写成 `$$` |
| `\( x \)` | 同样不渲染 | 改写成 `$` |
| `\$` | 显示字面美元符，KaTeX 不介入 | 想显示 `$` 就用它 |
| 代码块、行内代码里的 `$` | 安全，不参与解析 | 讲源码时放进代码里 |
| `\begin{equation}` | 能编译，但**不自动编号** | 编号只能手写 `\tag{}` |
| `\begin{align}` | 能编译，同样不自动编号 | 用 `aligned` + `\tag` |
| `\label` / `\eqref` | **编译报错** | 改用页面锚点链接 |
| 正文里的 `{` | MDX 当成表达式，容易编译失败 | 放进行内代码或写 `&#123;` |
| 正文里的 `<` | MDX 当成标签开头，编译失败 | 放进 `$...$` 或行内代码 |
| 公式里的全角空格、全角括号 | 报错或渲染异常 | 用 `\quad`、半角括号 |
| 公式里的中文 | 必须包 `\text{}`，否则报错 | `\text{其中 }` |

### H3 易错对照 20 条

左列是常见写法，右列是改对之后的源码。**看效果差别，别只看字符**：

| 场景 | 错 | 对 |
| --- | --- | --- |
| 多字符上标 | `x^n+1`（只把 n 当上标） | `x^{n+1}` |
| 多字符下标 | `a_ij`（只有 i 是下标） | `a_{i,j}` |
| 分式偷懒 | `1/2`（斜杠很小，论文里显廉价） | `\frac{1}{2}` |
| 分式分子多字符 | `\frac12 x`（只取首字符） | `\frac{1}{2}x` |
| 根式次数 | `\sqrt{x}[3]`（次数跑到根号外） | `\sqrt[3]{x}` |
| 括号不撑高 | `( \frac{a}{b} )`（括号比内容矮） | `\left( \frac{a}{b} \right)` |
| 花括号不转义 | `{1,2}`（直接报错） | `\{1,2\}` |
| 乘法用星号 | `a * b`（显示成普通星号） | `a \cdot b` |
| 集合描述法 | 直接写裸竖线（本行就是反例，会把表格断成多列） | `\{x \mid x>0\}` |
| 分段函数不分列 | `\begin{cases} x^2 & x\ge 0 \\ -x & x<0\end{cases}` 挤在一起 | 每行补 `&` 和 `,`：`\begin{cases} x^{2}, & x \ge 0 \end{cases}` |
| 换行写在普通公式里 | `a=1 \\ b=2`（块级里才生效） | 套 `\begin{aligned}` |
| 对齐忘了 `&` | `\begin{aligned} a=b \\ c=d \end{aligned}`（右侧不齐） | `\begin{aligned} a &= b \end{aligned}` |
| 用 `align` 当块级 | `\begin{align}` 无编号会疑惑 | `\begin{aligned}` 更稳 |
| 下标中文不包 `\text` | `A_失败`（报错） | `A_{\text{失败}}` |
| 单位斜体 | `10 m/s`（m、s 变斜体） | `10\,\mathrm{m/s}` |
| 微分斜体 | `\frac{d f}{d x}`（d 是变量斜体） | `\frac{\mathrm{d}f}{\mathrm{d}x}` |
| 省略号用点 | `...`（贴底，位置不对） | `\cdots` / `\ldots` |
| `\tag` 用在行内 | `$x^2 \tag{1}$`（报错） | 放进 `$$` 块级公式 |
| 交叉引用用 `\label` | `\label{eq1}`（编译失败） | 页面锚点 `[§A2](#a2-编号与交叉引用)` |
| 中文全角标点 | `（x）` 写在公式里（报错） | `\text{（}x\text{）}` 或半角 |

<Callout type="success">
改完这样自检一遍：① 每条公式的 `$$` 是否都独占一行；② 多字符上下标是否都加了花括号；③ 有没有残留 `\[ ... \]`；④ 表格行里的竖线有没有漏转义（表格错列十有八九是它）。四条全过，本站基本不会渲染翻车。
</Callout>
